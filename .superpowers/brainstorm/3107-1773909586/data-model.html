Section 1: Data Model Changes

New tables and columns to support all three features

New Tables

penalty_config_col
Configurable penalty settings
configIdserial PK
penaltyRatePercentnumeric (default 2.0)
penaltyFrequencyvarchar ('MONTHLY')
applicationMethodvarchar ('PENALTIES_FIRST' | 'FIFO')
gracePeriodDaysinteger (default 0)
updatedAttimestamp
penalty_ledger_col
Tracks accrued penalties per invoice per period
penaltyIdserial PK
invoiceIdFK → invoices_col
periodLabelvarchar ('Month 1', 'Month 2'...)
penaltyAmountnumeric
penaltyRatenumeric (rate at time of accrual)
accrualDatedate
statusvarchar ('ACTIVE' | 'PAID' | 'WAIVED')
paidAmountnumeric (default 0)
payment_allocations_col
How each payment was applied across invoices & penalties
allocationIdserial PK
paymentIdFK → incoming_payments_col
invoiceIdFK → invoices_col
penaltyIdFK → penalty_ledger_col (nullable)
allocationTypevarchar ('PRINCIPAL' | 'PENALTY')
amountnumeric
createdAttimestamp
ap_workflow_events_col
Timeline events for AP payment lifecycle
eventIdserial PK
poIdFK → purchase_orders_col
eventTypevarchar (see event types below)
eventDatajsonb (flexible payload)
performedByvarchar (user/supplier name)
notestext (nullable)
createdAttimestamp
Event types: CLAIM_SUBMITTED · DELIVERY_REPORT_UPLOADED · GR_CONFIRMED · INVOICE_SUBMITTED · THREE_WAY_MATCH · AP_CLERK_APPROVED · AP_CLERK_REJECTED · FM_APPROVED · FM_REJECTED · PAYMENT_SCHEDULED · PAYMENT_RELEASED

Modified Existing Tables

invoices_col + new columns
+ totalPenaltiesnumeric (default 0)
+ penaltiesPaidnumeric (default 0)
Denormalized totals for fast queries. Source of truth remains penalty_ledger_col.
supplier_invoices_col + new columns
+ workflowStatusvarchar ('PENDING_REVIEW' | 'AP_APPROVED' | 'FM_APPROVED' | 'REJECTED' | 'RELEASED')
+ claimDocumentUrltext (base64 data URI)
